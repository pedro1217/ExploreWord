# 🌍 ExploreWorld

### Sistema Web de Turismo e Hotelaria

O **ExploreWorld** é um projeto de conclusão do curso Técnico em Desenvolvimento de Sistemas da Proz Educação.

O objetivo é desenvolver uma plataforma web que permita aos usuários pesquisar hotéis, conhecer pacotes turísticos e realizar reservas de maneira prática e organizada.

## 🚀 Funcionalidades previstas

- Cadastro e login de usuários.
- Pesquisa de hotéis e destinos turísticos.
- Visualização de pacotes de viagens.
- Reservas de hotéis e pacotes turísticos.
- Histórico de reservas dos clientes.
- Painel administrativo.
- Gerenciamento de hotéis, quartos e pacotes.
- Recomendação de viagens por orçamento.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap
- PHP
- MySQL
