# Requisitos do Sistema — ExploreWorld

## 1. Descrição do Projeto

O ExploreWorld é um sistema web de turismo e hotelaria que permite pesquisar hotéis, consultar pacotes turísticos e realizar reservas.

Seu principal diferencial é recomendar opções de viagens de acordo com o orçamento do usuário.

## 2. Requisitos Funcionais (RF)

- **RF01:** Permitir cadastro e login de usuários.
- **RF02:** Exibir e pesquisar hotéis e destinos turísticos.
- **RF03:** Consultar pacotes turísticos e seus detalhes.
- **RF04:** Permitir realizar e consultar reservas.
- **RF05:** Recomendar viagens conforme o orçamento informado.
- **RF06:** Permitir ao administrador gerenciar hotéis, pacotes e reservas.

## 3. Requisitos Não Funcionais (RNF)

- **RNF01:** O sistema deverá ser responsivo para computadores e celulares.
- **RNF02:** Utilizar HTML, CSS, Bootstrap e JavaScript no frontend.
- **RNF03:** Utilizar PHP no backend e MySQL no banco de dados.
- **RNF04:** Proteger senhas e validar os dados dos usuários.
- **RNF05:** Utilizar PDO e consultas preparadas para acesso ao banco de dados.

## 4. Regras de Negócio

- **RN01:** Somente usuários autenticados poderão realizar reservas.
- **RN02:** As reservas dependerão da disponibilidade.
- **RN03:** As recomendações deverão respeitar o orçamento informado.
- **RN04:** Somente administradores poderão gerenciar hotéis e pacotes.

## 5. Considerações Finais

Os requisitos poderão ser ajustados durante o desenvolvimento do ExploreWorld.
